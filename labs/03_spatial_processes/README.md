# Лабораторна робота №3: Моделювання просторово-розподілених процесів (Теплопровідність)

**Дисципліна:** Моделювання процесів і смарт-систем<br>
**Мета роботи:** Моделювання одновимірного нестаціонарного процесу теплопровідності у твердому тілі товщиною $L$, що описується диференціальним рівнянням у частинних похідних параболічного типу:
$$\frac{\partial u(t, y)}{\partial t} = a \frac{\partial^2 u(t, y)}{\partial y^2}, \quad y \in [0, L], \quad t \ge 0$$
із крайовими умовами I роду $u(t, 0) = \alpha$, $u(t, L) = \beta$ та початковим розподілом температури $u(0, y) = \phi_0 = 0$.

Просторова дискретизація здійснюється методом ліній (сіток) на рівномірній сітці з $N=100$ внутрішніх вузлів, що зводить ПДР до системи 100 звичайних диференціальних рівнянь (ЗДР), яка інтегрується методом Рунге-Кутти 4-го порядку. Чисельний розв'язок порівнюється з точним аналітичним розв'язком у вигляді ряду Фур'є (30 гармонік).
