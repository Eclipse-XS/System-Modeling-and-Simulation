## 1. Структура графа та змінні

Мережа моделює ймовірність технічної відмови промислового верстата (`Machine failure`) на основі 7 дискретизованих вузлів:
1. `Type` (L, M, H — низький, середній, високий клас якості продукції);
2. `Air_temp_cat` (температура повітря: low, medium, high);
3. `Process_temp_cat` (температура процесу обробки: low, medium, high);
4. `Speed_cat` (швидкість обертання шпинделя, об/хв: low, medium, high);
5. `Torque_cat` (крутний момент, Нм: low, medium, high);
6. `Wear_cat` (час зносу різця, хв: low, medium, high);
7. `Machine failure` (цільова бінарна змінна: no / yes).

### Орієнтовані ребра графа:
- `Type` $\to$ `Torque_cat`
- `Type` $\to$ `Speed_cat`
- `Air_temp_cat` $\to$ `Process_temp_cat`
- `Torque_cat` $\to$ `Machine failure`
- `Wear_cat` $\to$ `Machine failure`
- `Speed_cat` $\to$ `Machine failure`
- `Process_temp_cat` $\to$ `Machine failure`

Структура графа є ациклічною (DAG). Параметризація здійснюється методом максимальної правдоподібності (MLE) через `DiscreteBayesianNetwork.fit()`.

## 2. Результати імовірнісного виведення (Variable Elimination)

| № | Назва сценарію | Вхідні свідоцтва (Evidence) | Найбільш імовірний стан | $P(\text{failure}=\text{yes})$ |
|---|---|---|---|---|
| 1 | Апріорна ймовірність (базова) | *Свідоцтва відсутні* | no ($91.33\%$) | 8.67% |
| 2 | Критичне навантаження | Високий знос (`high`) + високий крутний момент (`high`) | no ($76.63\%$) | 23.37% (зростання ризику у 2.7 раза) |
| 3 | Сприятливі умови | Низький знос (`low`) + низький момент (`low`) | no ($82.84\%$) | 17.16% |
| 4 | Теплове перевантаження + швидкість | Висока температура процесу + високий знос + висока швидкість | no ($82.87\%$) | 17.13% |
| 5 | Високий клас обладнання під навантаженням | Type = H + високий момент + високий знос | no ($76.82\%$) | 23.18% |
| 6 | Дослідження d-сепарації | Температура повітря = висока | $P(\text{Process temperature} = \text{high}) = 70.08\%$ | *Проміжний вузол* |
