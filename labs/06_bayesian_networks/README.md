# Лабораторна робота №6: Баєсові мережі довіри (Bayesian Networks)

**Дисципліна:** Системне моделювання (SS1)  
**Мета роботи:** Побудова ймовірнісної графічної моделі (Баєсової мережі довіри) на основі табличного набору даних:
1. Попередній розвідувальний аналіз (EDA) та квантування неперервних змінних на дискретні рівні.
2. Формування орієнтованого ациклічного графа (DAG) із фізично та логічно обґрунтованими зв'язками.
3. Оцінювання таблиць умовних імовірностей (CPD) методом максимальної правдоподібності (MLE).
4. Проведення імовірнісного виведення за допомогою алгоритму усунення змінних (`VariableElimination`) для різних наборів свідоцтв (evidence).
5. Графічна візуалізація структури мережі.

## 2. Чому саме `machine_failure` є канонічною?

У поглибленому аудиті [BAYESIAN_NETWORK_AUDIT.md](../../_audit_reports/20261108_audit/BAYESIAN_NETWORK_AUDIT.md) наведено детальні статистичні докази:
- У датасеті робіт рослин (`plant_growth`) 5 батьків для цілі утворюють $3^5 = 243$ конфігурації. При 193 рядках даних більше половини комбінацій взагалі ніколи не зустрічалися у вибірці, що робить умовні розподіли фіктивними.
- У датасеті відмов обладнання (`machine_failure`) 4 батьки утворюють 81 комбінацію на 10 000 записів. Модель демонструє різку та обґрунтовану зміну ймовірностей:
  - Базова ймовірність аварії: $8.67\%$.
  - За умови високого зносу та перевантаження крутним моментом: $23.37\%$ (зростання ризику у 2.7 раза).
