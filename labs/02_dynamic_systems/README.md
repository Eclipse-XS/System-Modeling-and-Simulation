# Лабораторна робота №2: Моделювання динамічних систем

**Дисципліна:** Моделювання процесів і смарт-систем<br>
**Мета роботи:** Чисельне дослідження поведінки складних динамічних систем за допомогою класичного методу Рунге-Кутти 4-го порядку (РК4):
1. **Завдання 1: Модель «хижак-жертва» (система Лотки-Вольтерри):**
   $$\begin{cases} \dot{x} = a_{11} x - a_{12} x y \\ \dot{y} = a_{21} x y - a_{22} y \end{cases}$$
   Аналіз періодичних коливань популяцій жертв $x(t)$, хижаків $y(t)$, побудова фазового портрета $y(x)$ та визначення стаціонарного стану рівноваги $(x^*, y^*)$.
2. **Завдання 2: Епідеміологічна модель поширення інфекції (SIR-модель):**
   $$\begin{cases} \dot{x} = -\frac{\beta}{H} x y \\ \dot{y} = \frac{\beta}{H} x y - \gamma y \\ \dot{z} = \gamma y \end{cases}$$
   Аналіз динаміки сприйнятливих (здорових) $x(t)$, інфікованих $y(t)$ та одужалих $z(t)$ при виконанні закону збереження чисельності $x(t) + y(t) + z(t) = H$, визначення дня та амплітуди піку захворюваності.
