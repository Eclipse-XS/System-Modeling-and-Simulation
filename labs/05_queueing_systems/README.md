# Лабораторна робота №5: Моделювання систем масового обслуговування (СМО / GPSS)

**Дисципліна:** Системне моделювання (SS1)  
**Статус у репозиторії:** 🔴 **ВІДСУТНЯ (ПОТРЕБУЄ РЕАЛІЗАЦІЇ / P0 BLOCKER)**

---

## 1. Констатація стану

У вихідному проєкті `SS1` та його підкаталогах лабораторна робота №5 **повністю відсутня**.
- Замість неї у корені репозиторію знаходився файл `5chm.py`, який реалізує метод скінченних різниць для крайової задачі ОДР 2-го порядку з курсу "Чисельні методи" і не має жодного відношення до теорії черг чи стохастичного моделювання. Файл ізольовано в папку `archive/legacy_numerical_methods/`.
- Жодних моделей GPSS (файлів `.gps`, `.fms`, звітів GPSS World) у проєкті не знайдено.

## 2. Методичні вимоги до виконання ЛР5

Згідно з університетською навчальною програмою, Лабораторна робота №5 передбачає побудову імітаційних моделей у спеціалізованому середовищі **GPSS World Student**:

### Завдання 1: Моделювання роботи автозаправної станції (АЗС)
- **Вхідний потік:** Автомобілі надходять на АЗС із розподілом інтервалів прибуття згідно з варіантом.
- **Обслуговування:** Заправка здійснюється через обмежену кількість колонок (наприклад, 2–4 колонки).
- **Спеціальні умови:** Періодичне прибуття бензовоза для зливу палива, що блокує роботу колонок або конкретної секції на час зливу.
- **Вихідні показники:**
  - Коефіцієнт завантаження паливороздавальних колонок (Utilization);
  - Середній та максимальний розмір черги автомобілів;
  - Середній час очікування в черзі та середній час перебування на АЗС;
  - Кількість відмов (якщо черга обмежена місткістю під'їзду).

### Завдання 2: Обробка запитів сенсорів розумного будинку (2-процесорна система)
- **Вхідний потік:** Різнорідні запити від датчиків розумного будинку (наприклад, охоронні датчики, температурні сенсори, телеметрія енергоспоживання).
- **Пріоритети:** Високопріоритетні аварійні повідомлення (охорона/пожежа) мають перевагу над періодичними фоновими опитуваннями (температура/вологість).
- **Архітектура обробки:** 2 процесори / сервери черги з різними дисциплінами вибору (з витісненням або без витіснення).
- **Вихідні показники:**
  - Завантаження процесорів;
  - Час затримки обробки пріоритетних пакетів у порівнянні з фоновими;
  - Ймовірність втрати або переповнення буфера черги.

## 3. Дорожня карта виконання для студента

Для отримання позитивної оцінки за ЛР5 необхідно:
1. Завантажити та встановити безкоштовну навчальну версію **GPSS World Student**.
2. Відповідно до свого індивідуального варіанта (для канонічного комплекту — **Варіант 15**):
   - Розробити лістинг моделі `gas_station.gps`;
   - Розробити лістинг моделі `smart_home_sensors.gps`;
3. Провести імітаційний експеримент на заданому часовому горизонті (наприклад, 480 хвилин робочої зміни або 10 000 транзактів).
4. Зберегти стандартні текстові звіти GPSS World (`.txt` / `.rep`) з показниками завантаження пристроїв (`FACILITY`, `STORAGE`) та черг (`QUEUE`).
5. Додати файли моделей та звітів до цього каталогу.
