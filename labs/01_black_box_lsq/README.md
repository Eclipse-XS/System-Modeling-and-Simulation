# Лабораторна робота №1: Моделювання систем типу «чорна скринька» методом найменших квадратів

**Дисципліна:** Моделювання процесів і смарт-систем<br>
**Мета роботи:** Побудова лінійної статичної моделі виду $y = a_0 + a_1 x_1 + a_2 x_2$ за експериментальними вибірковими даними за допомогою методу найменших квадратів (МНК), оцінка якості моделі за коефіцієнтом детермінації $R^2$, здійснення прогнозу у контрольній точці $(x_1 = 1.5, x_2 = 3.0)$ та тривимірна візуалізація регресійної площини.

---
