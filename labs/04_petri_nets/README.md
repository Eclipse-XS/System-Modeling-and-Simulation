## 1. Загальний опис та методологія

Лабораторна робота №4 виконувалася в спеціалізованому програмному середовищі моделювання мереж Петрі. Наведені в цьому репозиторії Python-скрипти є допоміжними інструментами, призначеними для програмного моделювання, генерації простору станів та графічної візуалізації поведінки дискретних динамічних систем.

Мережа Петрі формалізується п'ятіркою $N = (P, T, I, O, M_0)$:
- $P = \{p_1, \dots, p_m\}$ — множина позицій;
- $T = \{t_1, \dots, t_n\}$ — множина переходів;
- $I, O$ — функції вхідних та вихідних інциденцій;
- $M_0$ — початкове маркування (вектор розподілу фішок за позиціями).

Скрипт реалізує:
1. **Правило спрацьовування переходів:** Перехід $t_j$ є дозволеним (активним) за маркування $M$, якщо для кожної його вхідної позиції $M(p_i) \ge I(p_i, t_j)$. Спрацьовування переводить мережу у новий стан:
   $$M' = M - I(t_j) + O(t_j)$$
2. **Побудову графа досяжності:** Обхід у ширину (BFS) для знаходження всіх досяжних маркувань із $M_0$.
3. **Аналіз базових властивостей:** Оцінка обмеженості (максимальна кількість фішок у позиціях) та виявлення тупикових станів (deadlocks).
4. **Графічну візуалізацію:** Побудова орієнтованого графа простору станів за допомогою NetworkX та Matplotlib.
