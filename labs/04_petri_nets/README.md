# Лабораторна робота №4: Моделювання систем за допомогою мереж Петрі

**Дисципліна:** Системне моделювання (SS1)  
**Мета роботи:** Формалізація структури дискретно-динамічної системи у вигляді мережі Петрі $N = (P, T, I, O, M_0)$, моделювання спрацьовування переходів, динамічна генерація простору досяжних маркувань (графа досяжності), побудова матриць суміжності та переходів, а також теоретичний аналіз фундаментальних властивостей мережі:
- **Обмеженість ($k$-boundedness):** максимальна кількість фішок у будь-якій позиції.
- **Безпечність (1-boundedness / safeness):** чи не перевищує число фішок одиницю.
- **Збереженість (conservativeness):** інваріантність загальної суми фішок.
- **Живість (liveness):** відсутність тупикових маркувань (deadlocks) та можливість спрацьовування переходів.
- **Досяжність (reachability):** досяжність довільного маркування з початкового стану $M_0$.
